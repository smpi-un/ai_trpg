# AI-GM TRPG Engine

これは、GoogleのGeminiモデルをゲームマスター(GM)として利用する、テキストベースのTRPG（テーブルトーク・ロールプレイングゲーム）をプレイするためのアプリケーションです。

AIがシナリオをリアルタイムに解釈し、プレイヤーの行動に応じて物語を生成します。シナリオはMarkdownファイルで簡単に編集・作成することができ、プログラミングの知識がなくても自分だけのゲームを作ることが可能です。

## 特徴

- **AIゲームマスター**: GeminiモデルがGMとなり、動的で没入感のある物語を提供します。
- **シナリオのカスタマイズ**: `gamebook/` ディレクトリのMarkdownファイルを編集するだけで、ゲームのルール、シナリオ、登場人物を自由に変更できます。
- **3層アーキテクチャ**: AIの思考を「憲法(L1)」「短期記憶(L2)」「長期記憶(L3)」に分離することで、安定的かつ柔軟なゲーム進行を実現しています。

## インストール

1.  **リポジトリのクローン**: まず、このリポジトリをローカルマシンにクローンします。

2.  **Python環境のセットアップ**: このプロジェクトでは `uv` を使用したパッケージ管理を推奨しています。

    ```bash
    # 仮想環境の作成
    python -m venv .venv
    source .venv/bin/activate

    # 依存関係のインストール
    uv pip install -r requirements.txt
    ```

3.  **APIキーの設定**: `.env` という名前のファイルをプロジェクトのルートディレクトリに作成し、Google AIのAPIキーを記述します。

    ```
    GOOGLE_API_KEY="YOUR_API_KEY_HERE"
    ```

## 実行方法

以下のコマンドでゲームを開始します。

```bash
python src/main.py
```

ゲームが開始したら、AI(GM)の指示に従って、あなたの行動をテキストで入力してください。
ゲームを終了するには `exit` または `quit` と入力します。
