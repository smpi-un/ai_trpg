# ユーザーガイド

このドキュメントは、TRPGアプリケーションをプレイする利用者向けのガイドです。

## 1. ゲームの目的

このゲームは、AIがゲームマスター(GM)となって物語を進行する、一人用のテキストベースTRPGです。
あなたは物語の主人公として、状況に応じて行動を入力し、物語を進めていくことになります。

AIのGMが、あなたの行動に応じて情景を描写し、物語を紡いでいきます。

## 2. 準備

ゲームを始める前に、開発者から提供された指示に従って、以下の準備を完了させてください。

1.  **インストール**: 必要なライブラリをインストールします。
2.  **APIキーの設定**: `.env` ファイルに、指定されたAPIキーを設定します。

## 3. ゲームの始め方

ターミナル（コマンドプロンプト）で以下のコマンドを実行すると、ゲームが開始します。

```bash
python src/main.py
```

ゲームが始まると、まず最初にあなたの分身となるキャラクターの「能力値」がダイスによって決まります。
能力値には「腕力」「知力」「器用」などがあり、これらの数値が、特定の行動の成功率に影響します。

キャラクター作成が終わると、AIのGMからの最初のメッセージが表示され、物語が始まります。

## 4. ゲームの進め方

ゲームは、あなたとAIの対話形式で進行します。

1.  **状況描写**: AIが現在の状況や、あなたの周りの様子を描写します。
2.  **ステータス表示**: あなたの現在のHP（体力）や持ち物、能力値などが表示されます。
3.  **入力待ち**: `あなたの行動:` と表示され、あなたの入力待ちになります。

ここで、あなたが実行したい行動をテキストで入力し、Enterキーを押してください。

**入力例:**
- `あたりを見回す`
- `扉をこじ開ける` （腕力や器用さの能力値チェックが発生することがあります）
- `執事に話しかける`

あなたの入力に応じて、AIが物語の続きを描写します。特定の行動には「能力値チェック」が必要になることがあります。その際は、AIがダイスを振って、あなたの能力値と合わせて成功か失敗かを判定してくれます。

## 5. ゲームの終了方法

ゲームを途中で終了したい場合は、行動を入力する場面で `exit` または `quit` と入力してください。
